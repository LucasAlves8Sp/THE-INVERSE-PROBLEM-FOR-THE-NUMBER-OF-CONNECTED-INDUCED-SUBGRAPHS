# ConnectedSets: Lean formalization of the graph-theory paper

Lean 4 formalization of *The inverse problem for the number of connected induced subgraphs*
(the LaTeX source is `../paper/connected-induced-subgraphs-inverse-problem.tex`).

- Toolchain: Lean `v4.35.0` (`lean-toolchain`).
- Mathlib: commit `6015dbbfc399f4548bafd46f9560ff61595fd328` (`lakefile.toml`, `lake-manifest.json`).
- Size: 20 modules, 4623 lines (with the root file `ConnectedSets.lean`).
- No `sorry`, no `native_decide`, no `axiom` declarations.

## Build

```
lake exe cache get      # optional: download compiled Mathlib
lake build              # builds the library ConnectedSets
lake env lean CheckAxioms.lean
```

`CheckAxioms.lean` prints the axioms of the 31 statements of `ConnectedSets/Paper.lean`. Each
depends only on `propext`, `Classical.choice` and `Quot.sound`, except `theorem_1_2_minOrder`,
which depends on no axioms. `CHECKS.txt` records the results of every check.

## How Proposition 3.2 is proved here

The formal proof is an induction on connected sets; it does not use spanning trees as the paper
does. A vertex `y` of a connected set `S` is an *end* if `S` has exactly one connected subset
containing `y` of each size (`AS G S y = #S`).
- An end forces `NS G S = T #S` (`NS_eq_T_of_end`).
- An end gives an enumeration of `S` in which consecutive vertices are adjacent
  (`chain_of_end`), and no other pairs are adjacent (`no_chord_of_end`).
- If `NS G S = T #S`, then every vertex whose removal leaves `S` connected is an end
  (`end_of_tight`).
- Adding a vertex to a set with the minimum count, without producing a set with the minimum
  count, adds at least `2 #S - 3` connected sets (`attach_bound`).
- These steps give the dichotomy `NS_gap`. With the enumeration, they also give the isomorphism
  with `pathGraph n` (`iso_path_of_tight`).
